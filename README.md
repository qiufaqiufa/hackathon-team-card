# 组队名片生成器 - Hackathon Team Card Generator
在线预览：[点击访问项目](https://qiufaqiufa.github.io/hackathon-team-card/)
> 黑客松单人项目：一个纯前端的组队名片生成工具，帮助参赛者在组队环节快速展示自己、找到队友。

## 问题定义

黑客松组队环节常见痛点：

- **信息碎片化**：参赛者散落在微信群、Slack、Discord 等渠道，自我介绍格式不统一，难以快速对比。
- **表达能力有限**：纯文字消息缺乏视觉冲击力，容易被淹没在大量信息中。
- **效率低下**：每个人都在重复描述"我会什么、想做什么、想找什么人"，缺乏结构化的展示方式。

本项目通过**结构化表单 + 实时可视化卡片**，让参赛者在 30 秒内生成一张专业的组队名片，支持导出图片和复制文字两种分享方式。

## 核心流程

```
用户填写表单 → 右侧实时预览卡片 → 选择主题风格 → 导出PNG / 复制文字 → 分享到群聊
```

1. **填写信息**：左侧表单包含昵称、技能、期望队友、项目方向、自我介绍五个字段
2. **实时预览**：右侧卡片随输入同步更新，所见即所得
3. **主题切换**：深色科技风 / 浅色活力风两套主题一键切换
4. **导出分享**：导出 PNG 图片发群聊，或复制格式化文字直接粘贴

## 技术实现

| 技术 | 用途 |
|------|------|
| HTML5 | 页面结构 |
| TailwindCSS CDN | 快速样式开发，响应式布局 |
| 原生 JavaScript | 表单交互、实时同步、主题切换 |
| html2canvas | 将 DOM 卡片渲染为 Canvas 并导出 PNG |
| Clipboard API | 复制格式化文字到剪贴板 |

### 关键设计决策

- **单文件架构**：所有代码集中在一个 `index.html`，零构建、零依赖安装，浏览器直接打开
- **纯前端运行**：无后端、无数据库，数据不离开用户浏览器，隐私安全
- **实时同步**：通过 `input` 事件监听实现表单到卡片的毫秒级同步
- **XSS 防护**：技能标签渲染使用 `escapeHtml()` 转义用户输入

### 边界处理

- 文字超长自动换行（`word-wrap: break-word` + `word-break: break-word`）
- 空输入显示占位提示文字（斜体灰色）
- 输入框设置 `maxlength` 限制，防止超长内容
- 导出/复制前校验必填字段（昵称、项目方向），未填则提示

## 边界风险

1. **html2canvas 渲染兼容性**：渐变背景、`backdrop-filter` 等 CSS 特性在 html2canvas 中可能渲染不准确。不同浏览器版本表现不一致，特别是 TailwindCSS CDN 动态生成的样式可能在截图时丢失。**缓解方案**：导出前确保卡片在浏览器中正常显示；必要时可降级为纯色背景。

2. **Clipboard API 浏览器兼容性**：`navigator.clipboard.writeText()` 在非 HTTPS 环境或旧版浏览器中不可用。本地 `file://` 协议打开时部分浏览器会拒绝剪贴板权限。**缓解方案**：已实现 `document.execCommand('copy')` 降级方案。

3. **TailwindCSS CDN 生产限制**：CDN 版本在每次页面加载时动态编译样式，不适合生产环境。网络不通时样式完全失效。**缓解方案**：本项目为黑客松演示用途，可接受；如需离线使用，可将 TailwindCSS 编译为本地 CSS 文件。

4. **中文字体渲染差异**：不同操作系统（Windows / macOS / Linux）的中文字体渲染效果不同，导出的 PNG 可能与屏幕预览存在细微差异。

## 迭代方案

| 优先级 | 方案 | 说明 |
|--------|------|------|
| P0 | 增加更多卡片主题 | 添加 3-4 套主题（如赛博朋克、极简白、学术蓝），满足不同审美偏好 |
| P1 | 支持自定义头像上传 | 通过 FileReader API 读取本地图片，以 base64 嵌入卡片，增强个性化展示 |
| P2 | 添加名片模板预设 | 提供"前端工程师""设计师""产品经理"等预设模板，一键填充常见字段 |
